# Hoja de vida móvil

Aplicación Expo/React Native con cuatro pantallas navegables desde una barra inferior:

- **Inicio:** datos personales, perfil y acciones de contacto.
- **Estudios:** tres formaciones; el tecnólogo en curso se resalta visualmente.
- **Experiencia:** distingue la ausencia de experiencia laboral del proyecto académico Eco TRACE.
- **Hobbies:** intereses del CV con una alerta al tocar cada tarjeta.

## Ejecutar

```bash
npm install
npx expo start
```

## Validar

```bash
npx tsc --noEmit
npx expo export --platform web
```
